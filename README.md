# Masterclass NLP Repository

This repository is structured to help organize the different components of the **Masterclass NLP** project.

## 📁 Folder Structure
```
masterclass_nlp/
│-- lectures/       # Jupyter notebooks and educational materials
│-- streamlit/      # Streamlit app for NLP demos
│-- data/           # Raw and processed datasets
│-- models/         # Saved machine learning models
│-- project/        # Final NLP project implementations
│-- README.md       # Project documentation
```

## 🚀 Getting Started

### 1️⃣ Clone the Repository
```bash
git clone https://github.com/YOUR_GITHUB_USERNAME/masterclass_nlp.git
cd masterclass_nlp
```

### 2️⃣ Install Dependencies
Create a conda environment (or use virtualenv):
```bash
conda env create -f environment.yml
conda activate masterclass_nlp
```


### 3️⃣ Running the Streamlit App
```bash
cd streamlit
streamlit run app.py
```

## 📚 Project Components
- **Lectures:** Educational notebooks explaining key NLP concepts + code demonstration.
- **Streamlit:** Interactive web app for text classification, topic modeling, and visualization.
- **Data:** Preprocessed and raw datasets.
- **Models:** Saved models (e.g., TF-IDF vectorizer, LDA models, classifiers).
- **Project:** Final NLP application implementations.
